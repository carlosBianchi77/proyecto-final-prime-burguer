## Prime Burguer 🍔

##Proyecto final de la Diplomatura Universitaria en Desarrollo Web Full Stack.

##DESCRIPCIÓN

Sitio web desarrollado para una hamburguesería ficticia, utilizando HTML, CSS y Bootstrap.

##TECNOLOGÍAS UTILIZADAS

- HTML5
- CSS3
- Flexbox
- Grid
- Bootstrap

##Funcionalidades

- Página principal con presentación del negocio.
- Menú de productos.
- Formulario de contacto.
- Diseño responsive adaptable a distintos dispositivos.
